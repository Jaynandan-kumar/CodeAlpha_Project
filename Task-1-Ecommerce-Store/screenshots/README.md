10. `mobile-cart.png` — Cart page on mobile viewport

## How to capture

1. Open the application in Chrome
2. Use DevTools (F12) → Device Toolbar for mobile screenshots
3. Use Ctrl+Shift+I → Capture full size screenshot
4. Save images as PNG in this folder

## Recommended sizes

- Desktop: 1440×900
- Tablet: 768×1024
- Mobile: 375×812
